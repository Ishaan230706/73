## S1-01: Test file

```text
Using skills/scheme-dev, write tests/test_q3.rkt for S1 (Binary Tree Traversals) before any solution exists.

A tree is () or (value left right), a value being a number or a single-character symbol. The height of () is 0 and of a
node 1 + the larger height of its subtrees. A leaf is a node with two () subtrees. Left is visited before right.
The functions under test each end their output with a newline and use display:
- (print-inorder tree): one line, the inorder list.
- (print-all-traversals tree): three lines, the inorder, preorder and postorder lists.
- (print-height-and-leaves tree): one line, the list (height leaf-count).

Examples: t1 = (4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ()))) gives (1 2 3 4 5 6 7), (4 2 1 3 6 5 7),
(1 3 2 5 7 6 4) and (3 4); t2 = (1 () (2 () (3 () ()))) gives (1 2 3), (1 2 3), (3 2 1) and (3 1);
t3 = (a (b () ()) (c () ())) gives (b a c), (a b c), (b c a) and (2 2); the empty tree gives () on every line and (0 0).

Run the solution the way the grader does: copy code/*_q3.rkt, append calls, run racket, compare standard output
exactly and require empty standard error. Add edge cases (one node, only-left, only-right, repeats, negatives,
symbols, chains of depth 100 and 10000, a chain of 100000 to expose quadratic appending) and random trees checked
against simple reference definitions in the test. Compile the solution in a language that provides only the permitted
built-ins, with negative controls for that checker. Exit non-zero on any failure, without crashing if code is missing.
```
