# S2 prompts

Prompts drafted and carried out with Claude Code (Claude Opus 5.5) using `skills/scheme-dev/SKILL.md`.
They are word for word and in the order they were run, one prompt per commit.

## S2-01: Test file

```text
Using skills/scheme-dev, write tests/test_q4.rkt for S2 (Conditionally Insert into a Nested List) before any solution
exists.

(insert-if-short x lst n) inserts the atom x at the front of every list, at every level of nesting and including the
top one, whose number of top-level elements is less than n. The length is measured on the original list, before any
insertion. () has length 0, so it becomes (x) whenever 0 < n. There are no dotted pairs and n >= 0.
The interface under test: (print-insert-result) reads x, lst and n from standard input in that order and prints the
result with display and a newline, with no other text; my-length; my-map; (insert-if-short x lst n);
(make-inserter x len-ok?), returning a one-argument function that inserts into every list whose length satisfies
len-ok?; and a single definition of insert-if-short, which uses make-inserter.

Examples (standard input, then output):
42 ((1 2) (3 4 5) (6) ()) 3    gives  ((42 1 2) (3 4 5) (42 6) (42))
0 (((1) 2) (3) ((4 5 6) ())) 3 gives  ((0 (0 1) 2) (0 3) (0 (4 5 6) (0)))
7 () 3                         gives  (7)
7 () 0                         gives  ()

Run the solution the way the grader does: append calls to a copy, feed standard input, compare output exactly and
require empty standard error. Add edge cases (n = 0, n = 1, the exact threshold, symbols, input over several lines,
nested empty lists, depth 100 and 10000, lists of 10000 and 100000 elements, length predicates other than "less than
n") and random lists checked against a simple reference. Compile the solution with only the permitted built-ins
available (S2 also allows read), with negative controls for that checker. Exit non-zero on any failure.
```

## S2-02: my-length (S2.b)

```text
Using skills/scheme-dev, start the S2 solution file (code/<id>_q4.rkt, first line #lang racket/base) with
(my-length lst) for S2.b: the number of top-level elements of lst, where a sublist counts as one element and () has
length 0. Tail recursion with a count, using only the permitted built-ins. It must cope with 10000 elements and more.
```

## S2-03: my-map (S2.b)

```text
Using skills/scheme-dev, add (my-map f lst) for S2.b: the list of (f e) for each top-level element e of lst, in the
original order, with () giving (). One-list version only, written by plain structural recursion with cons (the result
is naturally a combination of the head and the recursive result), no map, append or reverse. Check that it copes with
lists of 100000 elements.
```

## S2-04: list-value?

```text
Using skills/scheme-dev, add the predicate (list-value? v) to the S2 file, telling a sublist from an atom without the
banned list?. Both () and any pair count as lists (the input has no dotted pairs); numbers and symbols do not.
```
