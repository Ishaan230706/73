# P1 prompts

Prompts drafted and carried out with Claude Code (Claude Opus 5.5) using `skills/prolog-dev/SKILL.md`.
They are word for word and in the order they were run, one prompt per commit.

## P1-01: Test file

```text
Using skills/prolog-dev, write tests/test_q1.pl for P1 (Department Assignment Puzzle) before any solution exists.

Four friends 'Alex', 'Ben', 'Carla', 'Dana' each have a different department (research, development, design,
testing), language (python, java, 'c++', javascript) and project ('AI', web, embedded, data). A solution is
[p(Name,Dept,Lang,Project), ...] in that order of names. The clues are:
1. The friend who prefers the AI project does not work in research and is not Dana.
2. Alex does not work in development and does not prefer C++.
3. The friend working in the testing department likes Python.
4. Ben prefers web projects and does not work in testing.
5. The friend whose favorite language is Java works in the design department.
6. Carla's project preference is not embedded, and her department is not development.
7. Dana's favorite language is not Java, and she works in research or testing.
8. The friend who prefers data projects works in research and does not use JavaScript.

The interface under test: clue(N,Solution); main/0, printing one solution of clues 1-8 as four lines like
"Alex = [research, python, AI]"; count_solutions(Active,N), counting the solutions of the clues in Active only;
and a clue 9 that names no friend, has a "% CLUE 9:" comment on the line directly above it, and leaves exactly
one solution.

Work out the expected values by brute force, independently of the solution. Test each half of every clue on a
failing example, every clue's count on its own, the count with each clue left out, duplicate and empty Active
lists, the exact grader command for main, silent loading, and the bans (assert, retract, global variables,
initialization, halt, other libraries). Find the solution as code/*_q1.pl so that the group ID is not repeated
in the test. Exit non-zero on any failure, and report a missing predicate as a failed test, not a crash.
```

## P1-02: values/2

```text
Using skills/prolog-dev, start the P1 solution file (code/<id>_q1.pl) with one predicate, values(Attribute, Values),
giving the values of each attribute: name ('Alex','Ben','Carla','Dana', in that order), department (research,
development, design, testing), language (python, java, 'c++', javascript) and project ('AI', web, embedded, data).
Facts only, with a declarative reading. Import only library(lists), which the generator will need.
```
